### 4. תשתית טכנית

**שמירת מילוי (sessionStorage):**
- `formData` — אובייקט גלובלי עם כל ערכי השדות
- `autoAssignFields()` — מזהה אוטומטי לשדות בלי name/data-field
- `captureFormData()` — נקרא לפני כל render שמוחק DOM
- `restoreFormData()` — משחזר אחרי כל render
- `persistNav()` — שומר עמוד/חלק/תצוגה
- ריפרש → חוזר ישירות לשאלון באותו חלק ותצוגה
- סגירת טאב → הכול נמחק (בטיחות נתונים רפואיים)

**תשתית תרגום:**
- `txt()` → שפה ראשית
- `txtOther()` → עברית מתחת כשמתורגם
- `otherDir()` → כיוון CSS לשורת הפניה
- `t3other()` → שפת הפניה
- `HELP_A` ו-`HELP_BC` — גלובליים, עם escape ל-`"` ו-`'`

**כפתורי ניווט:**
- 📝 רשימה | 📄 כמו הטופס | 📊 טבלה (רק ג')
- 📋 הצגת שאלון מלא | 🖨️ הדפסה
- פתיחה אוטומטית: כניסה לשאלון → חלק א' רשימה

**הדפסה:**
- CSS מסתיר: כפתורים, ?, קישורי חיפוש, הסבר מחקר
- מדפיס מה שעל המסך (חלק בודד / שאלון מלא)
